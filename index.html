About this archive: A morning report is published automatically each day using three live data feeds: NIFC WFIGS (fire incident locations & acreage), Oregon OEM ArcGIS (evacuation zones), and Oregon Dept. of Forestry records. Data is reviewed automatically at 4 PM PDT — an additional intraday report is published if a new wildfire evacuation order is issued. The PDF list is fetched live from the repository — any report added appears here immediately. PDFs are preserved indefinitely.
