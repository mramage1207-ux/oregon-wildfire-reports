Source-by-Source Audit

Sorted in the order each source enters the pipeline — fire/evacuation data feeds first, then community-resources sources, then this report itself.
Source Role in this pipeline AI use? Description
WFIGS (NIFC / IRWIN) Fire location, status, containment, acreage No AI Found Incident records come from human-entered situation reports (ICS-209/dispatch data), integrated across agencies by IRWIN's data-exchange rules — matching and deduplication logic, not machine learning. NIFC/USFS separately fund AI/ML research for satellite-based fire-perimeter detection, but that's a different product from the point-location feed this pipeline pulls.
NWCC Large Fire Information Structures threatened/damaged/destroyed No AI Found Manually compiled by incident management teams as part of standard situation reporting.
Oregon OEM evacuation zones Evacuation levels, zone boundaries, addresses affected No AI Found Zones are hand-drawn and maintained by county sheriffs/emergency managers on Esri's ArcGIS platform. Esri's own case study on Oregon OEM describes staff manually assembling map “portfolios” per event — no AI in how zones are determined.
Census TIGERweb (ZCTA boundaries) ZIP code geographic boundaries, used to map evac zones to ZIP codes No AI Found Static Census Bureau reference geometry on a fixed update schedule — not model-generated.
Open-Meteo Daily temp/wind/gust forecast, hourly humidity No AI Found This pipeline requests Open-Meteo's default model blend, which for the US resolves mainly to physics-based NWP (GFS / NOAA's National Blend of Models). Open-Meteo separately offers ECMWF's AIFS — an actual AI forecast model — as an optional endpoint, but this pipeline doesn't select it.
AirNow (EPA) Current AQI readings in the PDF; live AQI map embedded on the website Partial The values this pipeline fetches are real-time monitor readings (direct sensor data, not AI-derived). AirNow's separate multi-day air-quality *forecast* product increasingly blends machine-learning models with traditional chemical transport modeling, per EPA/NOAA's published methodology.
InciWeb Community-resources source (meetings, shelters, contacts) No AI Found Government interagency incident-information system, manually curated by fire Public Information Officers on a Drupal CMS.
centraloregonfire.org Community-resources source No AI Found Manually managed by Central Oregon Interagency Dispatch Center; no AI use found or disclosed.
County emergency-management sites Community-resources source No AI Found Standard local-government sites (e.g. readyjacksonco.com, bakercounty.org); no AI disclosed.
Oregon State Fire Marshal (OSFM) newsroom Community-resources source No AI Found Government press-release page.
American Red Cross Shelter location info AI Used The static shelter-locator map is a database lookup, but Red Cross's broader digital-assistance channel runs “Clara,” a published AI chatbot that helps disaster survivors find shelter and support services (in production since December 2020).
Local news sites Community-resources source for cross-border fires (idahonews.com, elkhornmediagroup.com, argusobserver.com) Unverified No public disclosure of AI use found for these specific outlets either way — flagged as unverified rather than asserted, since AI-assisted drafting is increasingly common in local news generally.
This report & website Community-resources search & drafting, evacuation-data reconciliation logic, report narrative, website features AI Used The most direct AI use in the whole system: every day, an AI assistant searches for and drafts the community-resources section, writes narrative summaries, and builds/maintains this website's interactive features — all under Matt Ramage's review and approval.
Bottom line: Across roughly a dozen external sources, only two have any confirmed AI involvement — EPA AirNow's forecast layer (not the raw readings this site uses) and the American Red Cross's Clara chatbot (not the shelter database itself). Everything else — fire locations, structure data, evacuation zones, ZIP boundaries, weather, and community-resource sources — is manually entered or curated, or standard physics-based modeling. The one place AI plays a direct role is upstream of all of it: this report and website are built and maintained by an AI assistant.
