About this report: Address counts come from Oregon OEM's Fire_Evacuation_Areas_Public feed. Each evacuation zone is mapped to its most likely ZIP code via the Census Bureau's geocoder (zone centroid → ZCTA). A ZIP with residents under multiple evacuation levels is listed once, at its peak level, with the address breakdown shown per level. This report is generated once daily as part of the morning wildfire pipeline; it is a supplementary geographic view of the same evacuation data shown by fire on the main report.
Data sourced from Oregon OEM ArcGIS (evacuation zones) and the U.S. Census Bureau geocoder (ZIP mapping).  •  Data Sources & AI Use
